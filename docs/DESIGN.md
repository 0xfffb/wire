# Wire UI 规范

视觉标准采用存档的 Linear 应用壳规范：

[docs/references/linear-app-DESIGN.md](./references/linear-app-DESIGN.md)

来源：[tastekit Linear Product App Design Spec](https://tastekit.dev/apps/linear/app/DESIGN.md)。第三方拆解，不是 Linear 官方 DS。

**实现以 `web/src/styles/global.css` 为准。** 色阶、字重、控件高度与那份对齐；本文只写 Wire 产品层差异。

Wire 是个人持仓展示：一台实例一份仓。访客看公开页；管理员进操作台连接券商、同步、决定公开范围。不做订阅、发现或月费。

## 原则

- `/` 是主人的公开仓位，不是发现列表，也不是营销 landing。
- 密度跟 Linear：侧栏行 28px，控件 32px，列表行 36px，顶栏 48px，4px 网格。
- 字重只用 400 / 510 / 590 / 680。标题 590，不用 500/600/700。
- 靛紫 `#5e6ad2` 只用于主按钮、品牌块、焦点。链接用 `#7170ff`。
- 绿 `#27a644` / 红 `#eb5757` 用于收益、盈亏，以及实盘标签。模拟盘用黄 `#e6b422`。不当其它 chrome。
- 用半透明细线分层，不用大阴影。动效 100–160ms `cubic-bezier(.25,.46,.45,.94)`。
- 数字 `tabular-nums`，价格/占比/收益右对齐。
- 收益旁保留非投资建议说明。
- 公开默认给股价，不给仓位大小。数量、市值、金额、成本、占比由分享页开关控制。现金始终显示。
- 只能纳入一个账户，因此公开页只有一个实盘或模拟盘标签。
- 占比含现金，按币种分别计算，不换汇。USD 仓加 USD 现金为 100%；HKD 同理。没有该币种余额就不列出。持仓和订单都标货币。现金表货币用纯文本，不用 pill。时间一律写到分钟，不用「今天 / 昨天」。
- 公开页只展示最后一次**成功**同步的快照。失败不撤数据，时间仍是上次成功。

不要做：发现/订阅/月费、纸色衬线账本、黑底 K 线仪表盘、营销大字报、卡片瀑布流当主列表、弹跳动画。

## 主题

`html[data-theme="dark"|"light"]` 决定已解析外观。  
`html[data-theme-pref="system"|"light"|"dark"]` 是用户选择。

| 选择 | 行为 |
| --- | --- |
| 跟随系统 | 跟 `prefers-color-scheme`，系统变化时同步 |
| 浅色 / 深色 | 锁定，不跟系统 |

默认偏好 `system`。写入 `localStorage` 键 `wire.theme`。

侧栏用**点选分段**：跟随系统 / 浅色 / 深色。不要改成下拉。

FOUC：`web/src/layouts/Base.astro` 里 inline script 在首屏前设置 `data-theme`。

| `--surface` | `#1c1c1f` | 面板、输入 |

| `--fill` | `#232326` | 导航 hover / 选中 |
| `--text` | `#f7f8f8` | 主文字 |
| `--text-2` | `#d0d6e0` | 侧栏标签 |
| `--muted` | `#8a8f98` | 次级 |
| `--faint` | `#62666d` | 说明、placeholder |
| `--line` | `#ffffff0d` | 分割 |
| `--input-border` | `#3e3e44` | 输入、次按钮 |

| `--up` / `--down` | `#27a644` / `#eb5757` | 盈亏 |

焦点：边 `#5e6ad2` + ring `rgba(94,106,210,.25)`。

## 布局

登录以外都是应用壳，但个人版不是铺满屏幕：整块居中成一张卡，最大宽度 1280px，左右留白。

```
          [ 卡 1280 ]
[ 侧栏 224 ] [ 顶栏 48 ]
             [ 内容     ]
```

两面：公开页给访客；操作台给管理员。没有订阅。

访客侧栏：品牌 → 仓位（`/`）→（底部）主题点选、语言、操作台。操作台进 `/admin`；未登录由 Worker 302 到 `/login`，已登录不要先闪登录页。

操作台侧栏：品牌 → 标签「操作台」→ 概览 / 连接 / 持仓 / 记录 / 同步 / 公开 / 资料 →（底部）主题、语言、账号、退出。账号行进资料。

顶栏：当前页名（13px）+ 槽位。公开页顶栏不放「操作台」，入口在侧栏底部。操作台顶栏只放「公开页」，不要手动同步按钮。同步走定时任务，记录在「同步」页。不要再放一套顶导航。

公开页：主栏资料（头像、名字、实盘/模拟盘标签、简介、社媒图标）+ 当前收益 + 上次成功同步 + 现金表（货币 / 余额 / 占比，只列有余额的货币）+ 仓位表；订单块仅在「显示订单」打开时出现，标题为「最近订单」。名字右侧用 pill 标明账户类型：实盘绿、模拟盘黄。未连接则无快照，只留资料或「还没有同步」。仓位未公开则只留资料。不要在顶栏放现金汇总、标的数、连接状态。不要右侧订阅面板。社媒只渲染已填的项；公开页用 16px 图标，放在 32px 底上（`--fill` + 细边），主文字色；hover 靛紫底白图标。文字放 `aria-label` 和 `title`。资料页标签同样带图标。

仓位表是 **表**，不是卡片网格。列：持仓、货币、股价、数量、市值、成本、盈亏、占比。盈亏 = 市值 − 成本，同一格写金额和相对成本的百分比。当前收益 = 各币种（市值 − 成本）/ 成本，不换汇，不含现金。订单表列：订单、方向、货币、股价、数量、金额、状态、时间。未开「显示数量」时，数量 / 市值 / 金额 / 成本 / 盈亏金额 / 占比模糊；股价、现金、当前收益、单行盈亏百分比仍可见。

登录页：居中卡，无侧栏；主题和语言仍放在卡内底部。实例还没有管理员时，同一张卡改成「设置管理员」（邮箱、密码、确认密码）。全站只有这一个管理员，设好后不再开放注册。

## 控件

| 控件 | 规则 |
| --- | --- |
| `.btn` | 靛紫底白字，高 32px，圆角 8。一屏一个主操作。 |
| `.btn.ghost` | 次按钮：`--surface` + `--input-border`。 |
| `.chip` | 工具条筛选。当前 `.is-on` 用 `--fill`。 |
| `.pill` | 只读标签，12px/510，1px 边。 |
| `.search` / `.form input` | 高 32px，圆角 8。焦点靛紫边 + `rgba(94,106,210,.25)` 环。 |
| `.theme-switch` | 三项点选。当前 `.is-on`。 |
| `.pref-select` | 仅语言。选项用各语言自称（中文 / English）。 |
| `.setting` | 公开设置一行：左文案右开关。 |
| `.holdings` | 表头 `--faint` 12px/510；数字右对齐。 |
| `.props` | `标签 + 值`，底部分割线。 |

涨跌：正数 `.up`，负数 `.down`，零或「—」用默认色。

## 文案与 i18n

- 界面默认中文。语言列表选择，不要点一下切换。
- 文案键在 `web/src/lib/i18n.ts`。chrome 用 `data-i18n`。简介只有一份，不跟语言切换。
- 语言写入 `localStorage` 键 `wire.locale`：`zh` | `en`。
- 加语种：往 `locales` 数组加一项，并补 `messages`。
- 专有名（handle、代码）不翻译。市场键用 `us` / `hk`，展示走 i18n。

仓位来自券商同步时点，不构成投资建议。不在侧栏底部重复写「演示数据 · 非投资建议」。

## 页面

| 路径 | 谁 | 作用 |
| --- | --- | --- |
| `/` | 访客 | 公开仓位。关闭公开则只有名字和简介。 |
| `/login` | 管理员 | 无管理员时：设置邮箱和密码，创建唯一管理员。已有管理员时：登录。已有会话则 302 `/admin`。无侧栏，卡底仍有主题和语言。不开放注册。 |
| `/admin` | 管理员 | 概览：连接状态、当前收益、是否公开、上次成功、最近变动。不显示现金汇总和标的数。未连接时空态去连接。需授权时标明但仍展示上次快照。 |
| `/admin/connect` | 管理员 | 一行 SnapTrade：连接 / 重新连接 / 断开，旁边是配置。点配置才到 Client ID / Consumer Key。未配置时点连接或概览「去连接」也进配置。纳入账户是单选，只能一个。 |
| `/admin/holdings` | 管理员 | 完整持仓（含货币）。未连接时为空。 |
| `/admin/activity` | 管理员 | 订单。未连接时为空。 |
| `/admin/sync` | 管理员 | 同步记录：时间、结果、说明。说明只写「成功」或失败原因。未连接时为空。 |
| `/admin/public` | 管理员 | 公开仓位、显示数量、显示订单、查看公开页。 |
| `/admin/profile` | 管理员 | 显示名、简介、社媒（图标 + X / 网站 / YouTube 链接）。 |
| `/legal/terms` `/legal/privacy` | 任何人 | 条款 / 隐私。 |

不要保留：发现、订阅、申请、预览、月费、注册。

### 公开开关

| 开关 | 默认 | 公开页效果 |
| --- | --- | --- |
| 公开仓位 | 关 | 关：`/` 不列仓、不成交。开：列仓，当前收益可见。 |
| 显示数量 | 关 | 关：数量、市值、金额、成本、盈亏金额、占比模糊。现金、股价、当前收益、单行盈亏百分比始终显示。开：与操作台相同数字。 |
| 显示订单 | 开 | 关：公开页无「最近订单」。 |

当前收益、上次成功同步、现金表、持仓表、订单表随「公开仓位」走，且必须已有成功快照。顶栏不显示现金汇总、标的数、连接状态。现金只列出有余额的货币，带该币种内占比，不换汇，不随「显示数量」模糊。当前收益按持仓成本现算，不换汇。

## 检查

新页面问这几句：

1. 还是侧栏壳，还是误做成营销站？
2. 仓位是表，还是又堆了卡片？
3. 靛紫是否只出现在主操作 / 焦点 / 品牌块？
4. 绿红是否只出现在盈亏和实盘标签？模拟盘是否是黄？
5. 主题仍是三项点选，语言仍是下拉？
6. 中英切换后标签、placeholder、title 是否都走 i18n？
7. 访客侧栏有没有混进控制台导航？
8. 有没有把发现、订阅、月费加回来？
